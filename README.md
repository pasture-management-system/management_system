# 清發畜牧場管理系統

一個完整的企業級畜牧場管理後台系統，使用 Python FastAPI 開發。

## 功能模組

### A. 基本資料作業
- **客戶資料管理** - 客戶編號、名稱、聯絡資訊、銀行帳戶
- **廠商資料管理** - 廠商編號、名稱、聯絡資訊、銀行帳戶
- **員工資料管理** - 員工編號、個人資訊、薪資設定、保險

### B. 進貨作業
- **進貨單管理** - 自動產生進貨單號 (P11411001 格式)
- **牛隻身份編號** - 自動產生 S/N (S11411211 格式，S=小牛, K=整隻牛)
- **雜項進貨** - 設備維修、辦公文具、飼料、耗損

### C. 銷貨作業
- **銷貨單管理** - 自動產生銷貨單號 (S11411001 格式)
- **牛隻出場** - 記錄出場重量、更新牛隻狀態
- **死亡記錄** - 記錄死亡日期、原因

### D. 營業報表
- 進貨報表 (月/季/年)
- 銷貨報表 (月/季/年)
- 損益報表
- 牛隻庫存報表
- 應付/應收帳款報表

### E. 系統重整
- 資料庫優化 (VACUUM)
- 資料庫分析 (ANALYZE)
- 完整性檢查

### F. 資料備份
- 手動備份
- 備份記錄管理
- 資料還原

### G. 會計系統
- 應付帳款管理
- 應收帳款管理
- 傳票管理
- 會計科目

### H. 薪資系統
- 月薪資計算
- 勞健保扣款
- 薪資發放

## 技術架構

- **後端**: Python FastAPI
- **資料庫**: SQLite
- **前端**: HTML + Bootstrap 5 + JavaScript
- **模板引擎**: Jinja2

## 安裝與執行

### 1. 安裝依賴

```bash
pip install -r requirements.txt
```

### 2. 執行應用程式

```bash
cd app
python main.py
```

或使用 uvicorn:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 3. 開啟瀏覽器

訪問 http://localhost:8000

### 4. 預設登入資訊

- 帳號: `admin`
- 密碼: `admin123`

## 編號規則

### 單據編號
- 進貨單: `P` + 民國年月(5碼) + 序號(3碼)，例如: P11411001
- 銷貨單: `S` + 民國年月(5碼) + 序號(3碼)，例如: S11411001

### 牛隻編號
- 格式: 類別(1碼) + 民國日期(7碼) + 序號(2碼)
- 類別: S=小牛, K=整隻牛
- 例如: S11411211 (114年11月21日第1隻小牛)

### 基本資料編號
- 客戶: C00001, C00002, ...
- 廠商: V00001, V00002, ...
- 員工: E00001, E00002, ...

## 民國年支援

系統全面支援民國年格式:
- 民國年 = 西元年 - 1911
- 所有報表可按民國年度篩選
- 單據編號使用民國年
